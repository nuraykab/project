Python Программирование

Возраст: 10-17 лет
Продолжительность: 12 месяцев (3 модуля)

Форматы обучения:

  • Офлайн: 2 занятия в неделю по 1,5 часа
  • Онлайн: 3 занятия в неделю по 1 час

Модули курса:

1 модуль - Python для начинающих

Основы языка: переменные, типы данных, операторы, условия и циклы

2 модуль - Продвинутый уровень

ООП, алгоритмы, структуры данных, работа с библиотеками

3 модуль - Практическое применение

Итоговые проекты, специализация, портфолио

Робототехника LEGO WeDo 2.0

Возраст: 5-9 лет
Продолжительность: 5 модулей по 16 уроков

Преимущества:

  • Максимум 4-5 учеников в группе
  • Индивидуальный образовательный набор
  • Продолжительность урока - 90 минут
  • Сертификат по завершению модуля
  • Гибкая система пропусков

Идеальный старт в мир робототехники для самых маленьких. Дети изучают основы механики, программирования и инженерного мышления через игру с LEGO.

Робототехника MINDSTORMS

Возраст: 9-17 лет
Продолжительность: 5 модулей по 24 урока

Преимущества:

  • Изучение языка программирования Scratch
  • Индивидуальный набор и планшет
  • Продолжительность урока - 120 минут
  • Участие в соревнованиях
  • Экзамен и сертификат по модулям

Продвинутый курс робототехники с изучением программирования и участием в соревнованиях. Развивает логическое мышление и инженерные навыки.

Робототехника Arduino

Возраст: 13+ лет
Продолжительность: 3 модуля по 24 урока

Преимущества:

  • Изучение языка программирования C++
  • Изучение схемотехники
  • Индивидуальный набор Arduino и ноутбук
  • Участие в соревнованиях
  • Продолжительность урока - 90 минут

Профессиональный курс электроники и программирования. Создание умных устройств, изучение микроконтроллеров и подготовка к инженерной карьере.
